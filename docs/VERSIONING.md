# Versionamento

A fonte canônica é `pubspec.yaml`.

Versão atual:

`version: 2.0.12+200026`

- antes do `+`: versionName exibido ao usuário;
- depois do `+`: versionCode Android;
- cada APK futuro precisa usar versionCode maior;
- versões oficiais não usam o sufixo `alpha`.

A versão `2.0.12+200026` corrige definitivamente o conflito das notificações e melhora seleção/exclusão de artifacts e os controles da tela de execução.
