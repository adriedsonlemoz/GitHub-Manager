# Versionamento

A fonte canônica é `pubspec.yaml`.

Versão atual:

`version: 2.0.18+200032`

- antes do `+`: versionName exibido ao usuário;
- depois do `+`: versionCode Android;
- cada APK futuro precisa usar versionCode maior;
- versões oficiais não usam o sufixo `alpha`.

A versão `2.0.18+200032` adiciona proteção contra envio do ZIP errado, identificação de versão nas Builds e reforça o cabeçalho sólido da tela inicial.
