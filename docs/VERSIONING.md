# Versionamento

A fonte canônica é `pubspec.yaml`.

Versão atual:

`version: 2.0.17+200031`

- antes do `+`: versionName exibido ao usuário;
- depois do `+`: versionCode Android;
- cada APK futuro precisa usar versionCode maior;
- versões oficiais não usam o sufixo `alpha`.

A versão `2.0.17+200031` corrige o topo da tela inicial e restaura a navegação de arquivos em repositórios acompanhados com segurança somente leitura.
