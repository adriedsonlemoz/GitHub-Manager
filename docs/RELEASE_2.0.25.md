# GitHub Manager 2.0.25+200039

## Interface

- remove o banner vermelho global de versão de teste;
- mostra a versão instalada em card vermelho/branco somente na confirmação de envio do ZIP;
- avatar da Home abre edição do perfil GitHub em popup responsivo;
- troca o menu de três pontos do repositório por engrenagem e diálogo centralizado de editar/excluir.

## Acompanhados

- aceita `owner/repo` e URLs completas de repositório;
- ao colar uma URL somente de perfil (`github.com/usuario`), lista os repositórios públicos para escolha;
- preserva cache local se uma atualização remota temporária falhar.

## Downloads

- serviço Android `dataSync` em primeiro plano durante downloads ativos;
- notificação persistente de progresso;
- arquivo parcial preservado em interrupções;
- retomada automática por HTTP `Range` quando suportado;
- botão mostra `Retomar download` quando existem bytes parciais aproveitáveis.
