# Dependências

O projeto prioriza Flutter/Dart e APIs nativas do Android.

Dependências principais:

- dio: GitHub REST API e downloads;
- flutter_riverpod: estado e serviços;
- go_router: navegação;
- flutter_secure_storage: tokens e chaves locais;
- sqflite: cache local;
- file_picker: seleção e exportação de arquivos;
- archive: ZIPs e artifacts;
- pinenacl: criptografia de GitHub Secrets;
- xml: importação XML de Secrets;
- path/path_provider: armazenamento e Central de Downloads.

O APK oficial é Release universal e valida `armeabi-v7a` e `arm64-v8a`.
