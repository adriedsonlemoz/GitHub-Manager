# GitHub Manager 2.0.78

Versão: `2.0.78+200092`

Release de correção de integração do fluxo de envio e Builds. Corrige retorno tipado da confirmação, pré-check contextual de permissões, carregamento seguro de branches, abertura de uma execução específica a partir da aba Builds, polling adaptativo, estados de Actions e fallback de projetos sem workflow. Inclui testes novos para as regressões principais.
