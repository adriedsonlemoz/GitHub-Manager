# GitHub Manager 2.0.31+200045

## APKs e Artifacts

- cards mais compactos e informativos;
- botões Baixar, Publicar e Excluir menores e lado a lado;
- identificação visual de APK, AAB/Play, Debug, Profile, Release, prévia e estabilidade provável;
- versão, tamanho, data e workflow run visíveis no card;
- classificação de estabilidade sinalizada como inferência quando depende do nome do artifact.

## Envio de ZIP

- regressão de versão permitida com aviso;
- divergência de nome deixa de bloquear;
- uma divergência forte de applicationId ou package vira alerta;
- duas divergências fortes ativam risco alto;
- mesmo em risco alto existe confirmação secundária para forçar o envio ao destino exibido.
